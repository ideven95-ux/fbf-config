# fbf-config

## Free Book Finder Chrome Extension

Available from: [https://chromewebstore.google.com/detail/free-book-finder/pgigmeimlophkafmgjnnaebngdhnegno](https://chromewebstore.google.com/detail/free-book-finder/pgigmeimlophkafmgjnnaebngdhnegno)

Basically if you need ANY textbook, ebook, or audiobook etc, just use it. It will search for all the free (legal) sources and show you the results. If no free version exists, then it'll show the cheapest options. It does NOT search illegal or pirate sites!
